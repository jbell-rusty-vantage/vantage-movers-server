Every mutation requires one Idempotency-Key per intent, reused unchanged after uncertain failure. Revision conflicts refetch authoritative values, retain unsent draft and require explicit resubmission; no automatic rebase. Existing source evidence is baseline only, not proof of this continuation.

Manual attachment uses existing host `GET /api/v1/admin/search?q=...&database_scope=production&limit=10`, consumes only Current Form/Call Leads, and then reads the exact Number+Lead pair. Existing pair uses edge revision; absent pair uses Number revision and Number `attach_lead` availability. Search does not mutate. First-attachment audit uses an explicit unlinked prior state. Official host links use `database_scope=production`, unlike CSI API `scope=production`.

Lead/latest-call/related records come from additive Outreach reads. Voicemail/provider connection never implies human contact. Read-only timeline uses the real merged cursor and retains notes, reasons, assignments and prior values. Clock policy and Attention ranking stay on the server; idle clock scans no longer churn aggregate revisions.
