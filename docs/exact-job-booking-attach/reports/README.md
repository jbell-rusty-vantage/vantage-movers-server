# Completion reports

One report per issue, named `EJBA-0<n>-completion.md`. An issue is not
`complete` in [`../PROGRESS.md`](../PROGRESS.md) until its report exists
here.

- **Evidence, not assertion.** Paste command output. "Tests pass" is not
  evidence.
- **State what you did not do.** Name the issue's out-of-scope list.
- **Redact.** No unmasked phone, email, full customer name, or secrets.
