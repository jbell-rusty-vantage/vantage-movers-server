Persist the deferred hold and pending Owner review; preserve company activity, routes, historical records and expired-run checkpoints. This records a shutdown ID, not a successful final ingestion run.

- `general-apply` / `general-verify --call-plan <file> --checksum <Call checksum> --expected-database vantagemovers --deployment <SHA> --run-id <ID>`: use an independently bound general-backfill ledger, ordinary audited Call commands and actual Sheet membership. Retain per-row skips, repeated-identity provenance, Booking/refund accounting, exact match edges and proposed financial values. Omitting `--source-only` retains the older combined planning modes.
