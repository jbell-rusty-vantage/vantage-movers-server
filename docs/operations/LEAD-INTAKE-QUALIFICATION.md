# Phase 3 Lead intake qualification

## Selected write and production baseline

The November 16 22:00 through November 17 22:00 New York insertion cohort contained 19 WordPress Forms, 25 Granot-created Forms and seven RingCentral Calls. Indexed ObjectId windows, a 30,000-row limit per collection and an eight-second query budget bounded discovery. No collection reached the cap. The worker identified the serving Granot release 9bbe2c7c. Form and Call creations retain their original snapshots, audit descriptors, qualification and reporting intent.

The final Detailed Call Log generated 138 canonical final-result executions across 12 Calls, retaining 178,348 BSON bytes with zero joined EntityChanges. For each command we searched a 15-second oplog interval from its application second, joining its exact execution ID. In 133 transactions the only operations were the receipt insert and a Call update on the referenced ID with the observation timestamp and Mongoose update time. These receipts measured 171,882 bytes. Five remaining executions lack this transaction classification. Estimate at this observed day's confirmed mix: 171,882 logical BSON bytes/day and 133 fewer inserts/day. This excludes indexes, oplog, compression and physical storage. Different arrival and rescan rates change the estimate.

## Intake and rollback

A public Form reaches runExistingCreateFormLead with a server-built context. Its transaction records the original submission, Form Fill work, canonical execution, revision, EntityChange and Sheet intent. Distinct duplicate submissions are saved. Replaying the same command identity reuses its original result. The RingCentral adapter admits a qualified inbound Call and records the processed provider identity, Lead, revision, EntityChange and Sheet intent. Subsequent processed-call polls may supply newer final evidence. An exact or stale observation does no work. A later identical result now advances the timestamp in the same qualified Call, after verifying server provenance and rereading the facts in a retryable transaction. A genuine correction retains the complete canonical transaction and post-commit finalization.

Rollback restores src/services/domainCommands/ringcentralFinalResult.ts from 9bbe2c7c through the same release workflow. That source reads the same timestamp, Call, command, audit and outbox formats. Previously omitted polling receipts have no replay dependency. Old and new workers order by the same stored timestamp. The Granot expiry guard remains in the base release.

## Proof and rollout criteria

The disposable Mongo 8 single-member replica fixture uses actual Form and RingCentral intake with local registry configuration, queued Sheet intent and test provider boundaries. Run the same fixture from each source checkout with a fresh database suffix. For baseline execution, the fixture can be copied outside the repo and invoked from 9bbe2c7c. Each MEASURE line gives net document count and BSON by collection and the driver's issued write commands, including retried attempts. The rollback fault uses a validator only inside the disposable database. Run the candidate's before/after evidence against its assertions with node --import tsx ops/capacity/lead-intake-replica.cjs after <fresh-suffix>.

Release requires matching reviewed tree, passing focused proofs, full regression, lint and typecheck, hosted retention and matching diagnostics on the production configuration, READY preview with application/database smoke and a fresh unchanged main. Production must identify the reviewed SHA at the alias and worker, with healthy application and database. Stop on unexpected admission, stale winner, missed genuine effect, duplicate billing/outbox, health failure, mismatched identity or retention/diagnostic drift. For an attributable regression restore the prior final-result writer. Observe actual post-rollout traffic with bounded reads of provider/Lead, command, change, Sheet and oplog evidence. Separate durable BSON per confirmed operation, daily extrapolation and filesystem movement. Reassess the existing capacity watch at 90% used or acceleration.
