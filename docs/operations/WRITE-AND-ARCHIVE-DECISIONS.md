## First assignment — cost of an official Booking or Cancellation

Trace a linked Booking, a leadless or Referral Booking, a Cancellation, a correction and a retry of the same command. Start with the existing [Bookings](../knowledge/services/bookings.md), [Cancellations](../knowledge/services/cancelled-lead.md), [Cancellation mirror](../knowledge/services/cancellation-mirror.md) and [Agent allocation](../knowledge/services/agent-allocation.md) contracts. Use the existing local replica fixtures with fake delivery. Obtain a bounded read-only sample for the live mix where available.

1. For each path, count application commands, Mongo inserts, matched and modified updates, bytes retained by collection, and downstream jobs enqueued and completed. Include the command ledger, EntityChange, Lead mirrors, Customer and Agent allocations, Sheet intent/attempts and Outreach nominations where the path produces them. Distinguish a retry from a later correction with a new business effect.
2. Identify one repeatable source of avoidable work. Candidates include rewriting an identical mirror or enqueuing equivalent projection work twice for one committed revision. Show which readers and recovery paths depend on each write. If the fixtures already suppress it, record the baseline and move to the next candidate.
3. Deliver a baseline and candidate table per outcome. Estimate daily BSON avoided as the sum across paths of daily arrivals times measured bytes avoided per arrival. Use the same method for writes and jobs. Report the measured mix, busy-hour and 2× scenarios, p95 delivery lag and the assumption that could erase the gain. Mark unknown frequencies explicitly. Count a downstream write saved by two proposals once.
4. Compare exact official outcomes, linkage, snapshots, allocation credit, Master Leads and Master Booked tab memberships and row values, plus Outreach admission and due work. Exercise concurrent linkage, retry after commit, transaction rollback and a genuinely changed correction. Keep any proposal that changes freshness or visible history separate for an Owner decision.

**Exit for this assignment.** Record which writer to change, its expected daily gain, the parity proof and rollback, or the measured reason to defer. Phase 4 has no measured per-outcome savings yet. The November Granot intake numbers below are outside its denominator.
