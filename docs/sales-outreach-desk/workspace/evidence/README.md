# Evidence entry point

Store task-specific synthetic evidence in a directory named by SOD task and stage. Include HANDOFF.md with the handoff template, CHECKS.md with exact commands/results, source/projection/config revisions, snapshots of synthetic states and redacted latency/reconciliation reports. Current preparation VALIDATION-REPORT.md is at packet root. No runtime acceptance evidence exists yet. Do not store credentials, actual phone/name content, raw provider payloads, transcripts or production exports.
