## Decisions made unattended

1. **validate.mjs** fails on pre-existing `sources/` hash drift (see above). Not fixed (packet docs read-only); recorded for the coordinator.
2. **Index script:** the `migration:csi:indexes` script no longer exists (`scripts/migrations` untracked since `ce5f856c`). New `ops/sales-outreach/build-indexes.ts` (`pnpm outreach:indexes`): `--target=<db>` required and must equal the resolved database; plan (read-only) by default; `--apply` builds only missing indexes; same-name/same-key mismatches and unique-index duplicates refuse the run; production apply passes `assertProductionWriterMatchesDeployment`.
3. **Router mount:** `src/app.ts` mounts `sales-outreach.routes.ts` ahead of `v1Routes`; the router applies `requireApiSecret`, the `scope` check and the guard itself (no edit to `v1.routes.ts`).
4. **Unsigned / bad signature → 403 `FORBIDDEN`** (not 401), so the admin BFF never mistakes a desk refusal for an expired session; 401 stays for a missing/invalid API secret.
5. **No env flag on the desk:** desk Rep access uses `requireSignedCsiRep` (no `SALES_INTELLIGENCE_REP_ACCESS` dependency); the SI `requireCsiReader` behaviour is unchanged.
6. **Manager signature** = seven-line payload with role `manager`; a manager request carrying an Agent header is refused.
7. **Configuration encodings (engineering-owned per CONTRACTS):** `working_days` as `{iso_weekday, open_minute, close_minute}`; added fields required by approved policy but missing from the CONTRACTS field list: `initial_response_working_minutes` (P02d), `sms_sequence` (P03), `quoted_open_minute` (P04a), `priority_map` (P05c/P05d), `intake_default_rule` as a per-source object (P05e). Every "rule" field is a closed enum naming the single approved behaviour. Roster = explicit `goals.rep_work_schedules` (P08a "explicitly selects"); the installer resolves "every reviewed `sales_rep` link" at install time, so a newly reviewed rep needs a re-run or an Owner edit.
8. **Pointer carries its version's `content_hash`** so every read fetches only the pointer and reuses an immutable cached version keyed by version + hash.
9. **`expected_revision: 0`** is the explicit Owner initialization (creates revision 1).
10. **Identical content** PATCH returns `changed: false` and writes no version/pointer/audit; the command-ledger row is still written (it is the idempotency record).
11. **Timestamps:** desk models use `defineCsiModel`'s `createdAt`/`updatedAt` instead of separate `created_at`/`updated_at` fields.
12. **Installer actor** is `csiOperatorActor` (fixed id `sales-intelligence-operator`, kind owner, request id derived from the content hash). It refuses when the active configuration is `unavailable` (the Owner repairs it first).
13. **Enrollment runs** use a caller-chosen unique `run_key` (resumable apply; re-runnable verify) instead of a unique manifest+phase+partition, because `report` writes nothing.
14. **Rep-day rows** add `count_scope` and `unattributed` (FAST-TRACK M1: never present one scope as the other).
15. **Activation validation:** shadow/enforcement require complete cadence + evidence + goals; `goal_metrics_enabled` requires goals; `intake_admission_enabled` requires `intake_admission_at`. SMS capture absence is an informational blocker only (FAST-01 continues without SMS).
16. `received_quality` values: `instant | wall_clock | missing | unreliable` (phase 3 may refine with the restored adapter).
