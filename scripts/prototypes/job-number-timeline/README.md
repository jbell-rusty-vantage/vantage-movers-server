# Job Number timeline

Typed Job Number search that assembles the owner-facing chain —
including events that happened **before** the Lead had a Job Number —
plus the Sheet Sync jobs those writes requested.

The product is **retrieval + how the timeline looks**. There is no
catalog of every Job Number.

CLI modes (once implemented): `render --job-no <raw>` (the search),
`discover` (ops helper for proof-shape examples).

A follow-on Admin agent ships a **new** dashboard tab (gold `New`
badge, same pattern as Intakes) and must Write the components with
the 21st.dev MCP and CLI. It must not restyle the forensic
`JobTimeline`.
